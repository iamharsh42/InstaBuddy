# **InstaBuddy**

**InstaBuddy** is an AI-powered platform developed as a major project for my B.Tech degree. The platform is built using **Flask**, **ReactJS**, and **TypeScript**, combining robust backend functionality with a seamless user interface.

## **Key Features**
- **AI Recommendation Systems:**  
  - **Content-Based Recommendation System:** Suggests items based on user preferences and content similarity.  
  - **Collaborative-Filtering Recommendation System:** Provides recommendations using data from similar users.  

- **AI Chatbot:**  
  - Integrated an AI chatbot trained on custom data to deliver personalized user interactions.  

- **Seamless User Interface:**  
  - Designed and developed an intuitive and user-friendly interface for optimal user experience.

## **Technologies Used**
- **Frontend:** ReactJS, TypeScript  
- **Backend:** Flask  
- **AI/ML:** AI-powered recommendation systems and chatbot  

This project demonstrates the practical application of artificial intelligence in creating personalized and interactive platforms.
